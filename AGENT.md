# AGENT.md

Technical reference. Operator guides are in `ops/`.

## Architecture

- **Static site** in `docs/`, published by GitHub Pages from `main:/docs`. No build step, no package manager, no tests. Vanilla ES modules.
- **Database**: one Google Sheet, shared "Anyone with the link: Viewer".
- **Reads** (public page): the browser queries the sheet through the gviz endpoint (`https://docs.google.com/spreadsheets/d/<id>/gviz/tq?tqx=out:json`), no API key. On failure it falls back to the Apps Script web app `GET`.
- **Writes** (admin panel): `POST` to the Apps Script web app (`google-sheet/Code.gs`, bound to the sheet, deployed as Web app, execute as owner, access Anyone), authenticated by a shared password.
- **Config**: `docs/config.json` → `{ "sheetId", "appsScriptUrl" }`. Empty or invalid `sheetId` → the site uses the sample data in `docs/data/`.

## Public page

- `?a=<slug>` album page; no `a` → store profile; unknown slug → not-found message.
- `&theme=<key>` forces a theme for that view.
- `#preview=<base64url JSON>` renders an unsaved album (used by the admin **Preview**).
- Visitor theme pick is stored in `localStorage['bw-theme']`, honored only when `themeSwitcher` is TRUE.
- Untrusted data is rendered with `textContent`/attributes only; only `ICONS` strings use `innerHTML`.
- `example.com` links and bare social home pages are treated as empty.

## Admin panel

- `docs/admin/`. Settings in `localStorage['bw-admin-sheet']`: password, site URL (default `../` of the admin URL), country. Web app URL is always taken from `config.json`.
- **Save & test** calls `ping`; if the returned `spreadsheetId` differs from `config.json`, it shows the JSON to commit.
- Sticker link = `<siteUrl>?a=<slug>`. NFC writing uses Web NFC (`NDEFReader`, Android Chrome only). `share.js` computes NTAG213/215/216 fit.
- Auto-fill requires web app `version >= MIN_API_VERSION` (`autofill.js`).

## Sheet schema

Headers are matched by name; column A of Albums must be `slug`.

- **Albums**: `slug, title, artist, year, label, note, cover, shopUrl, spotify, appleMusic, youtubeMusic, youtube, amazonMusic, deezer, tidal, soundcloud, bandcamp, updatedAt`. All cells plain text.
- **Site**: `key | value | notes`. Keys: `name, tagline, theme, themeSwitcher, catalogUrl, socials.{instagram,facebook,tiktok,x,youtube,whatsapp,email,maps,website}, texts.{listen,play,shop,catalog,follow,notFound}`.
- **How to use**: human notes, not read.
- Slug: `^[a-z0-9]+(?:-[a-z0-9]+)*$`, max 60.
- Themes: `ink, paper, fire, sun, cover`.

## Apps Script API (`Code.gs`)

- `GET` (no auth): no action → `{ok, service, version}`; `?action=site`; `?action=album&slug=`.
- `POST` body (sent as `text/plain` JSON to avoid CORS preflight): `{action, password, ...}`.
  - `ping` → `{spreadsheetId, spreadsheetName, albums, version}`
  - `listAlbums`, `getAlbum {slug}`, `deleteAlbum {slug}`
  - `saveAlbum {album, isNew, expectedUpdatedAt}` → `CONFLICT` if `updatedAt` changed since load
  - `getSite`, `saveSite {site}`
  - `uploadCover {base64, mimeType, slug}` → file in Drive folder "Backwash Records covers", shared view-only
  - `autofill {url, country}` → reads a Spotify/Apple Music/Deezer album link, matches on iTunes Search and Deezer APIs
- Response: `{ok: true, ...}` or `{ok: false, code, error}`. Codes: `AUTH, SETUP, BAD_REQUEST, NOT_FOUND, EXISTS, CONFLICT, RATE_LIMIT, SERVER`.
- Writes run under `LockService` script lock. Wrong password adds a 1 s delay.
- Script properties: `ADMIN_PASSWORD` (set by hand), `COVERS_FOLDER_ID` (set automatically).
- `setup()` creates/repairs tabs, headers and Site keys, and adds the demo row when Albums is empty; idempotent, never deletes data. Run it after each Code.gs update to grant new OAuth scopes.
- `API_VERSION` constant: bump when the admin depends on new server behavior, and raise `MIN_API_VERSION` in `autofill.js` to match.
- Deploying an update: paste code → run `setup` → **Manage deployments → Edit → New version**. A **New deployment** changes the URL and requires a `config.json` update.

## Keep in sync

| Change | Files |
|---|---|
| Album column or platform | `Code.gs` (`ALBUM_HEADERS`, `PLATFORM_KEYS`), `platforms.js` (`PLATFORMS`), `tools/make_sheet_template.py`, `docs/data/albums/demo.json`, `icons.js` |
| Site key | `Code.gs` (`SITE_KEYS`), `platforms.js`, `data.js` (`SITE_KEYS`), `make_sheet_template.py`, `docs/data/site.json` |
| Theme | `Code.gs` (`THEME_KEYS`), `platforms.js` (`THEMES`), `docs/assets/css/themes/<key>.css`, `docs/themes.html`, `make_sheet_template.py` |
| Slug rule | `Code.gs` (`SLUG_RE`), `platforms.js` (`SLUG_RE`) |

## Tools

- `python3 tools/make_sheet_template.py` → `google-sheet/backwash-records-template.xlsx` (needs `openpyxl`; deterministic output).
- `python3 tools/make_logos.py` → `docs/assets/img/*` from `brand/*.jpg` (needs Pillow, numpy).
- `node tools/build-icons.mjs` → `docs/assets/js/icons.js`. Run from a scratch npm dir; see the file header for packages.

## Local run

```bash
python3 -m http.server 8000 -d docs
```

Open `http://localhost:8000/?a=demo` and `http://localhost:8000/admin/`. With a `sheetId` in `config.json` the page reads that live sheet; with an empty one it uses `docs/data/`.

## Deploy

Push to `main`. GitHub Pages ("Deploy from a branch", `/docs`) publishes in 1–3 minutes. Pages serves with ~10 min browser cache. Sheet edits need no deploy.
